Text Editor

College

For the project, we were required to create a text editor for a fictional client.


The project needed to be created in C# using Visual Studio. The Project also needed to include accessibility features to make it usable by all.


Here is the link to the GitHub Repository: https://github.com/Kaytster/Kaytsters-TextEditor

My Text Editor is inspired by existing programmes such as Microsoft Word and Wordpad.

For the colour scheme I chose purple and cyan.

Main Functions


  • Saving and opening a file.
  • Changing the font size and style.
  • Changing the text colour and highlight colour.
  • Viewing the word and letter count.
  • Switching between dark and light mode.
  • Changing the font size of the application itself.
