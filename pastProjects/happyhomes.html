HappyHomes

College

For this project, we were required to make some kind of E-Commerce website of our choice.


The site could be built using only HTML, CSS and JavaScript. No frameworks were permitted. For the development environment we were only permitted to use Notepad (not Notepad++, just normal notepad). Our site must also be accessible.


Here is the link to the GitHub Repository: https://github.com/Kaytster/Kaytsters-HappyHomes-Website

For my concept, I chose a housing site. The colour scheme needed to make sense and also meet accessibility needs, so I went with green and orange as they fit with the home theme.

This was my first time ever creating a website, and doing it in Notepad (with no help from programs like VS Code) was very challenging.

Main Functions


  • Use the navigation bar to switch between pages easily.
  • About Us - View information about the company.
  • Contact - Get in touch using the simple form.
  • View your account.
  • Fill out the checkout page to order products.
  • View products.

There is are a lot of things that don't work, such as the search bar, creating an account and using it, adding products to cart.

Some time in the future I would love to revisit this and make a new version with these core features implemented!
