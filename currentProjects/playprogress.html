PlayProgress

Personal

PlayProgress is a tracker for Gamers, designed to log game time and achievements. Inspired by already existing sites such as Backloggd.


I wanted to create my own version of videogame tracker sites, such as Backloggd. I always feel there are features missing that I would like to see in such a website, so decided to challenge myself to develop one.


Here is the link to the GitHub Repository: https://github.com/Kaytster/PlayProgress

I have chosen to create this project using PHP, and Bootstrap CSS. I have used Bootstrap many times and I am comfortable using it for my framework. PHP however, I have only used once so I decided I wanted to improve my skills by using it for this project.

Main Functions


  • Users can choose to signup or login from the landing page of the site.
  • The Dashboard will display recent stats like 'Latest Added Game' and 'Latest Achievement'.
  • The navigation bar will link to: Dashboard, Library, Achievements, Logs, and Account.
  • In Library, users can see all their games and add new ones. They will be displayed by the order they were added, but a tag function will allow users to filter by console. They can also search for specific games.
  • In Achievements, the main page will display the users top 3 games (top 3 with the most achievements). Clicking onto view all will display every achievement the user has completed in order.
  • In Logs, users can use the calender to select a specific date and see the logs for that date, or create a new one. Creating a new one requires selecting the game and date, and they can input a title, playtime, any notes from the session, and select any achievements completed for that game.
  • In Accounts, users can change their profile picture or username, and can see stats such as total games, achievements and playtime.
